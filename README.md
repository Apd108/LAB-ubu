## ✨ What Even Is LAB-ubu? (The Lore)

Every hardware student knows the heartbreak: you spent 45 minutes wiring an 8-bit ripple counter on a crusty breadboard, only for a loose jumper wire on column 23 to ruin your entire evening. 

**LAB-ubu** solves that with pure diva flair. 💅

It is an uncompromising, interactive 3D laboratory simulator running right in your web browser. You get an authentic **Scientech ST-2001 Digital IC Trainer Console** side-by-side with a bench of professional **Rigol Test & Measurement Gear**—rendered with realistic materials, physical shadows, glowing LEDs, tactile switches, and high-frequency real-time circuit simulation.

Whether you're studying digital logic gates, clocking master-slave JK flip-flops at 1Hz, or inspecting diode clippers and clampers on a virtual Rigol oscilloscope, LAB-ubu gives you the tactile joy of hardware engineering with zero toasted components.

## 🧸 Cute Features That Slay

- 🎀 **Tactile 3D Breadboard with Strip Highlighting**  
  Wide-spaced, authentic breadboard holes with dynamic green 5-hole terminal strip glow, vertical plug sleeves, and 100% solid, opaque jumper wires that never look faint.
- ⚡ **Authentic ST-2001 Digital Trainer Console**  
  Featuring 10 red toggle switches (`S10` down to `S1`) with true 3D lever angles, 10 domed red LED Lamp Monitors (`L10` down to `L1`) with intense emissive cores, a 1Hz–1MHz square wave clock generator, and a debounced mono pulser.
- 📈 **Real-Time Rigol Instrument Bench**  
  Seamlessly switch from Digital to Analog mode to reveal the **Rigol DS1102E Dual-Channel Oscilloscope** and **Rigol DG822 Arbitrary Function Generator** running a real-time mathematical waveform solver.
- 🎯 **Docked Live Inspector Pill**  
  Hover over any socket, IC pin, hole, or jumper wire to see instant pinout labels, logic states (HIGH/LOW/TRI), and node voltages right in the header bar with zero layout jitter.
- ↩️ **Time-Travel Undo / Redo & Checkpoints**  
  Wire fearlessly! Press `Ctrl+Z` to undo any placement or connection, `Ctrl+Y` to redo, and use **💾 Save State** and **📂 Restore Saved** to bookmark your progress.
- 🧸 **Chibi ECE Lab Assistant Mascot & 8-Step Spotlight Tour**  
  Need help finding your way around? Click the adorable animated chibi assistant in the bottom right corner for an interactive 8-step tour featuring dynamic SVG mask cutouts and 3D camera-tracked spotlight rings.

## 🍓 Run Her Locally (Quick Start)

Get LAB-ubu running on your machine in under two minutes:

```bash
# 1. Clone the repository
git clone https://github.com/Apd108/LAB-ubu.git

# 2. Step into the laboratory
cd LAB-ubu

# 3. Install the dependencies
npm install

# 4. Fire up the Vite dev server
npm run dev -- --host
```

Now open **`http://localhost:5173`** in Chrome, Edge, Brave, Firefox, or Safari (WebGL 2.0 required).

### 🧪 Run the 100% Verification Test Suite
To run the automated electrical verification suite across all 34 circuits:

```bash
node runVerify.mjs
```
